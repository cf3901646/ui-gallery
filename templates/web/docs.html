文档入门快速开始

快速开始

用 5 分钟把 Kite 接入现有的 Web 项目：安装 SDK、初始化客户端，然后写入第一条实时同步的数据。

开始之前

需要 Node.js 18.17 或更高版本，以及一个 Kite 项目。可以在控制台免费创建，每月含 50 万次读写。

1. 安装 SDK

在项目根目录运行：

终端
npm install @kite/sdk@3.2

也支持 pnpm add @kite/sdk 和 yarn add @kite/sdk，压缩后约 38 KB。

2. 初始化客户端

新建配置文件，填入控制台“项目设置”里的项目 ID：

src/kite.config.ts
import { createClient } from "@kite/sdk";

export const kite = createClient({
  projectId: "prj_8f3k2m9q",
  region: "cn-shanghai",
  // 浏览器端只用公开密钥
  publicKey: import.meta.env.VITE_KITE_PUBLIC_KEY,
  offline: true,
});

注意

不要把 secretKey 写进前端代码或提交到仓库。泄露后请立即在控制台轮换。

3. 写入并订阅数据

src/todos.ts
const todos = kite.collection("todos");
await todos.add({ title: "发布 3.2 版本", done: false });

// 任何客户端修改后，回调会在 100 ms 内触发
todos.where("done", "==", false).subscribe(render);

配置参数

参数类型默认值说明
projectIdstring—必填，控制台中的项目 ID
regionstring"cn-shanghai"数据区域，另有 cn-beijing、ap-singapore
offlinebooleanfalse写入先存入 IndexedDB，联网后自动同步
timeoutnumber10000单次请求超时，单位毫秒
