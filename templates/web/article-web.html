弹簧动画参数怎么调：SwiftUI 与 Compose 对照表

阻尼比和响应时间两个数字，就能描述 90% 的界面动效。本文给出常用场景的推荐值，以及两个平台落地时的差异。

许
许沐阳2026年5月14日 · 9 分钟阅读

做动效时最常听到的反馈是“有点肉”或者“太弹了”。这些感受其实都能落到两个参数上，只要团队用同一套词，设计稿和代码就不会各说各话。

为什么用弹簧，而不是缓动曲线

缓动曲线要同时指定时长和形状，动画被打断时速度会突变。弹簧只描述物理属性，被打断时从当前速度继续，这正是手势驱动的界面需要的。

好的动效让人察觉不到它的存在，只觉得界面“跟手”。

两个参数就够了

SwiftUI 用 duration 和 bounce 描述弹簧，Compose 用 dampingRatio 和 stiffness。换算之后，它们说的是同一件事：

  • 阻尼比：1 表示不回弹，越小越弹，界面里很少低于 0.6。
  • 响应时间：大致等于到达目标所需的时间，0.2–0.5 秒最常用。

阻尼比怎么选

按下、切换这类高频操作用 1.0；卡片展开、页面转场用 0.85 左右，有一点生命感但不抢戏；只有庆祝类反馈才值得用到 0.6。

响应时间怎么选

移动距离越大、元素越大，响应时间越长。下面是同一个“按下缩放”在两个平台上的写法：

// SwiftUI
withAnimation(.spring(duration: 0.25, bounce: 0)) {
    isPressed = true
}

// Jetpack Compose
val scale by animateFloatAsState(
    targetValue = if (pressed) 0.96f else 1f,
    animationSpec = spring(dampingRatio = 1f, stiffness = 1400f)
)

常用场景推荐值

场景阻尼比响应令牌
按钮按下1.00.25 ssnappy
开关切换0.90.3 ssnappy
卡片展开0.850.4 ssmooth
底部面板0.880.45 ssmooth
点赞反馈0.60.35 sbouncy

落地清单

  1. 设计稿里标注阻尼比和响应时间，而不是贝塞尔曲线。
  2. 把常用组合做成令牌：spring.snappy、spring.smooth、spring.bouncy。
  3. 手势结束时把手指速度传给动画，否则松手会“顿”一下。
  4. 系统开启“减弱动态效果”时，把回弹换成淡入淡出。
